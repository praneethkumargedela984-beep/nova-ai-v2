
# NOVA AI V2 — Project Plan

## 1. Mission
Build a reliable, secure, futuristic AI assistant with a black-and-crimson interface.

## 2. Requirements
- Budget: strictly ₹0.
- Primary device: Android tablet.
- Platform: responsive website, with an Android app as a later goal.
- AI: real AI responses, not simulated replies.
- Conversation: maintain relevant context across messages.
- Voice: add speech input and spoken responses; investigate continuous voice conversation.
- Design: polished, accessible, mobile-friendly interface.

## 3. Security
- Never commit API keys, passwords, or private tokens.
- Store backend secrets in the hosting provider's secret manager.
- Never expose secrets in frontend code, browser responses, or logs.
- Validate requests and handle errors safely.
- Use HTTPS and restrict cross-origin requests where appropriate.

## 4. Reliability
- Build in small, testable stages.
- Keep the project documentation up to date.
- Test success cases and failure cases.
- Verify mobile layout and accessibility.
- Do not mark features complete until tested.

## 5. Budget
Use free tools and services only. Check free-tier limits before choosing a service. Never activate a paid service without permission.

## 6. Development Stages
1. Foundation and documentation.
2. Frontend interface.
3. Secure backend.
4. Real AI integration.
5. Conversation context.
6. Voice capabilities.
7. Android packaging.
8. Final security and reliability review.

## 7. Definition of Done
A feature is complete only when it has been implemented, tested, documented, and its limitations are understood.
